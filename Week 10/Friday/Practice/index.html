GitHub Pages Deployment Lab

Prepare a static site for deployment, check its public URL, and provide a friendly not-found page.

1. Pages setup

  1. Push the site to the default branch of a public repository.
  2. Choose Settings → Pages → Deploy from a branch.
  3. Select the default branch and the repository root, then save.
  4. Wait for the deployment status and open the published URL.

2. Check the not-found route

After deployment, visit a made-up path under the project URL. Add a root-level custom 404 page and check that its home link returns to the site.
