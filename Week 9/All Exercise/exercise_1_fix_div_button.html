Exercise 1 - Fix a Div-Button

Beginner · Replace a non-semantic clickable div with a real button.

Task

Fix the div being used as a button. Use a real button, add a visible keyboard focus style, and give the close button an accessible name.

  1. Replace the outer <div class="btn"> with <button type="button">.
  2. Add a :focus-visible style.
  3. Add aria-label="Close" to the close button.
  4. Test with Tab, Enter and Space.

One possible solution

<button type="button" class="btn" onclick="alert('Clicked!')">Submit form</button>
<button type="button" aria-label="Close" onclick="alert('Closed')">✕</button>

  outline: 3px solid #f59e0b;
