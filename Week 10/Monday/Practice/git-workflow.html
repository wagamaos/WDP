Git Workflow Lab

Practice a clean local history: create a repository, make a feature branch, merge it, then connect a remote.

1. Create a first commit

Run these commands from a new practice folder. Add a simple index.html before staging.

git init
git status
git add index.html
git commit -m "Create starter page"
git log --oneline

2. Branch and merge a change

Keep the stable page on main. Create a feature branch, add a stylesheet, commit it, and merge it back.

git switch -c feature-styles
git add style.css
git commit -m "Add page styles"
git switch main
git merge feature-styles
git log --oneline --graph

3. Connect and publish the repository

Create an empty public GitHub repository named webpro-w9. Replace the example URL with its URL; do not put passwords or tokens in the remote URL.

git remote add origin https://github.com/YOUR-USERNAME/webpro-w9.git
git remote -v
git push -u origin main

Confirm the files and commit history appear on GitHub. The homework page contains the project prepared for this push.
