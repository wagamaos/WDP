React Portfolio Gallery

Build a portfolio gallery from reusable React components and filter the projects by technology.

Completed project

The React source project is in Week 11/portfolio-gallery. It uses data-driven components and filters the cards in response to the selected technology.

  • ProjectCard renders the title, description, tech stack, GitHub link, and demo link.
  • ProjectList renders three projects from the project data array.
  • FilterBar filters projects by technology and supports an All option.
  • ProfileCard, NotificationList, and reusable Card components implement the props, defaults, conditional rendering, keys, and children exercises.
  • Submit the GitHub repository URL on Cybercampus before the next class.
