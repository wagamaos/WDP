Exercise 3 - Fix Accessibility Issues

Intermediate · Improve a sign-up form using accessible HTML.

Task

Fix at least two accessibility issues in this sign-up page.

  1. The icon-only button has no accessible name.
  2. The email input has no label.
  3. The error text should not rely on colour alone.
  4. The linked image has generic alt text.

Starter code

One possible solution

<button class="icon-btn" aria-label="Search">🔍</button>

<label for="email-field">Email address</label>
<input type="email" id="email-field" aria-describedby="email-error">
<p class="error" id="email-error">Error: Please enter a valid email address.</p>
<p class="error">Error: Password too short.</p>
