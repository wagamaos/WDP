Why Forms?

Forms allow users to send data to a server.

Real-World Form Examples

  • Login: Username and password
  • Search: Keyword to find information
  • Registration: Name, email and password

Google Search Form

GET vs POST

GET Method

Data is appended to the URL. Commonly used for searches.

Example: /search?q=javascript

POST Method

Data is sent in the request body. Commonly used for registration.

HTTPS is still needed to protect sensitive information.

Key Points

  • Forms collect and submit user input.
  • HTML provides structure.
  • CSS controls appearance.
  • JavaScript can validate user input.
