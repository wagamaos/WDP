WEB ACCESSIBILITY PRACTICE FILES

This folder contains 12 standalone HTML files:
- practice_1 through practice_9: one for each of the nine topics
- exercise_1 through exercise_3: one for each practical exercise

HOW TO USE
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open any HTML file in a browser, or use the Live Server extension.
4. Each file runs independently; no external libraries are required.

The practice pages include short reviews and small interactive tasks.
The exercise pages include starter code, a check/preview where appropriate, and an optional solution.
