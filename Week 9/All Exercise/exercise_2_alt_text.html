WEB ACCESSIBILITY · A11Y

Exercise 2 - Add Proper Alt Text

Beginner · Give images useful text alternatives.

Task

Fix the four image alternatives according to their purpose.

  1. Campus photo: write descriptive alt text.
  2. Decorative wave: use an empty alt attribute.
  3. Logo linking to homepage: describe the destination.
  4. Bar chart: briefly describe the information shown.

Starter code

One possible solution

<img src="campus.jpg" alt="Gachon University campus building">
<img src="wave.svg" alt="">
<a href="/"><img src="logo.png" alt="Gachon University homepage"></a>
<img src="enrollment.png" alt="Bar chart showing enrollment rose from 1,200 in 2024 to 1,476 in 2026">
