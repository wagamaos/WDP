WEEK 10 MONDAY HOMEWORK

The site in this folder is prepared for the GitHub Pages assignment.

1. Create a public GitHub repository named webpro-w9.
2. From this folder, initialize Git, add and commit index.html.
3. Add your own repository URL as origin and push the main branch.
4. In GitHub, open Settings > Pages and deploy from main, folder / (root).
5. Test the live URL and submit both the repository and Pages URLs.

The GitHub account and remote repository must be supplied by the student; no
external account changes are made from this local exercise.
