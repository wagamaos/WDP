WEEK 10 FRIDAY HOMEWORK

The Book Search app in this folder is the static site to prepare for GitHub
Pages. It searches Open Library from the browser and does not need a server.

1. Test index.html locally and search for a title or author.
2. Create a public repository named webpro-book-search.
3. Push the contents of this folder so index.html is at the repository root.
4. Enable Pages from the default branch and repository root.
5. Test the published search page and a nonexistent route.

Pages deployment, the GitHub repository, and the final public URL require the
student's GitHub account and must be completed there.
