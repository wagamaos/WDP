# Portfolio Gallery

Week 11 React practice and portfolio-gallery assignment. The app includes the
requested `ProfileCard`, `NotificationList`, `Card`, `ProjectCard`,
`ProjectList`, and `FilterBar` components.

## Run locally

```sh
npm install
npm start
```

Update the project entries in `src/data/projects.js` with your own work before
submitting your GitHub repository URL on Cybercampus.
